# RSC 非棋牌迁移补全与上线准备（2026-09-21）

> 后续真实赛事同步问题及再次修补、接管边界，见 [正式接管前再次复核](final-review-2026-09-21.md)。

本轮继续对照运行中的旧 RSC、原生插件和生产论坛组合。生产旧 RSC 仍是资金来源；本轮没有切换真实交易，没有改生产 YAML、Git checkout 或 Nginx。棋牌游戏继续排除。

## 新补齐与纠正

| 范围 | 处理 |
| --- | --- |
| 管理资产重置 | 恢复 cash / total_equity 两种模式；保留持仓权益与待结算预测本金。目标不足时，连同撤单、清仓、账本调整全部回滚，冻结状态保持。 |
| 红包公共分享 | 游客可查看发起人、总额、份数和状态，再登录领取；不暴露分配结果或领取名单。GET 过期预览不退款、不记账，论坛的全站登录限制仍有效。 |
| 资金与打赏后台 | 新旧转账、帖子打赏、红包、发行和资产调整统一分页；按类型、状态、用户名/ID、话题查询，保留旧失败记录。 |
| 标的审批 | 支持外部搜索、一键录入、现有标的去重、旧带交易所前缀的申请、拒绝与审计。HTTP 报价验证在资金锁以外执行。保留旧最小数量、手续费、退市市场及不支持产品限制。 |
| 搜索需求 | 统计旧归档及新搜索记录，大小写合并，优先显示无结果需求；本地列表搜索也记录，输入防抖，只读预览不写入。 |
| 每日奖励后台 | 按待发、已发、冻结筛选，显示待发总额及分页；预览继续只读。 |
| 延期赛事 | 针对最近比分列表之外仍有本金待结算的比赛，按 ESPN 原事件 ID 回查；不覆盖人工赛果，保持赛果确认等待时间；补“立即检查并结算”。 |
| 指数适配 | 补齐旧 16 个指数的供应商映射，包括 KOSPI 等漏项；已导入目录只修复旧默认映射，不覆盖管理员自定义映射。 |
| 外汇计价 | FX:EUR 等保持“每单位外币以 USD/RSC 计价”，修复错误使用反向货币对的默认适配，历史金额不改写。 |
| 未声明的行情延迟 | Yahoo 没有声明延迟时，观察开市期间连续前进的报价时间；稳定延迟进入确认交易模式。休市、前日价格和停更报价不能不断延长有效期。显式声明 0 延迟不被推断覆盖。 |
| 身份差异 | 默认仍拒绝缺失用户和未核对改名。新增绑定导出 SHA256 的身份核对清单；已核对改名沿用原 ID，无其他业务依赖的缺失钱包可隔离冻结托管，保留原身份与全部原始历史，不创建冒名账号、不转给别人。 |
| 原生整合 | 打赏按钮、弹窗、汇总、用户卡及通知由 RSC 自身实现。组合验收移除了旧 RSC 打赏主题组件，不要求继续维护它。 |

旧收益率的核对结论已纠正：运行中旧容器的 `exchange.js` 和 `points.js` 与本地对应构建产物一致，未加载遗留 `performance.js`。当前旧排行榜采用总盈亏 / 还原本金口径，原生报表继续保持；历史时间加权观测节点仅用于归档展示。“另建连续 TWR 引擎”不是迁移当前线上功能的前提。

## 正式切换步骤与边界

1. 保持用户指定的正常 A/B 构建方式，仅增加 RSC 插件仓库安装行；不固定 Discourse 或其他插件版本，不改其他 YAML 配置。
2. 停止旧 RSC 写入与发奖/交易/赛事任务，导出最终快照，重新核对身份清单并重复完整导入和对账。正式开启前，原生插件、行情任务、奖励任务和通知保持关闭。
3. 沿用已核对的使用组/管理组、限额及风险开关，核对世界杯徽章配置。缺失账号资金以冻结托管保留，不作归属转移。
4. 停用旧 RSC 打赏主题组件（生产 theme 39），启用原生按钮与通知，确认只有一个资金写入方；随后启用行情和业务任务，观察实际队列、报价及限额。
5. 使用 [旧页面跳转样例](../deploy/legacy-web-redirects.conf.example) 替换旧 Web 入口，保留原 TLS 配置与域名。论坛 `/app-rsc-api` 代理应随旧主题下线处理，不把旧 JWT 写请求盲转为新资金请求。
6. 开放真实交易后的回退不能简单重新启动旧账本：必须先停新写入并核对切换后的增量，避免两套资产状态分叉。

最近最多 200,000 行当前 Nginx 日志中，观察到 9,924 次 `/app-rsc-api` 请求：9,922 次打赏汇总查询、1 次旧认证交换、1 次打赏；其中 146 次 Android WebView 请求。未观察到独立原生 HTTP 客户端不等于证明它不存在；没有据此提前关闭线上旧接口。

短时来源检查与 worker 重启测试已完成，但不能声称覆盖所有市场开闭盘、供应商限流或长期停机情形。正式上线仍需最终停写快照、生产开关/徽章配置、入口切换及上线观察；本轮准备和私有验证不等同于已经接管真实资金。
