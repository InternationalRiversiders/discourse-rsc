## 验证与本轮修复

1. 完整原始导入拒绝缺失身份，失败后账本和历史表均为空。
2. 子集完整事务演练通过，结束回滚后账户、账本、历史表均为 0；事务运行约 132 秒。
3. 同一子集实际提交到隔离库，事务约 126 秒。`script/verify_legacy.rb` 逐条比对全部历史、每个钱包和各项托管资金；4,341 个账户的余额均与分录一致，每笔分录平衡。
4. 保存 PostgreSQL 15 格式备份，并实际恢复到第二个隔离数据库。恢复后的记录数、账面资金与双边分录总和再次核对通过。
5. 后端回归 52 个测试、263 项断言通过；导出专项 4 个测试通过。涵盖批次中途失败的完整回滚、金额精度、历史奖励防重及演练子集限制。

真实规模下修正了导出遗漏世界杯活动表、旧取消状态兼容、失败订单文字，并改为先校验身份、分批写入历史及期初分录。期初分录仍通过原账本服务和数据库约束，全部批次处于同一事务中。新增非游戏业务表未列入清单时会拒绝导出，避免静默遗漏。
