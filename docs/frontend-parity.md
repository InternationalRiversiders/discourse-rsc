# 股市界面对照与本次改进

对照对象：旧项目 `web/components/exchange/ExchangeApp.tsx` 的 `market-workbench`、`market-board`、`mobile-market-detail` 和账户概览。

上一版原生试用只提供了一个标的下拉框，缺少旧版的行情浏览首页。这会影响先比较行情再下单的习惯。本次恢复“列表 → 标的详情 → 下单”，并统一页面样式。

| 旧版体验 | 本次原生实现 |
| --- | --- |
| 市场分类 | 按实际载入标的生成分类，支持原有分类名称 |
| 首页列表 | 代码、名称、RSC 最新价、本币价（有数据时）、日涨跌、状态和迷你走势 |
| 标的搜索 | 对当前载入目录按代码、名称搜索，展示空结果 |
| 行情分页 | 每页 20 个，筛选后回到第一页 |
| 涨跌比较 | 增加按涨幅/跌幅排序，无昨收数据的标的排在末尾 |
| 桌面选中联动 | 左侧列表保持可见，右侧更新图表、价格、交易状态及下单标的 |
| 手机详情 | 首屏显示列表，点选标的后展示详情，可返回原列表保留筛选 |
| 账户概览 | 可用余额、保证金、仓位权益、浮动盈亏、持仓数量；最近历史报价用于展示估值，缺价时按成本估值并明确标注 |
| 持仓与订单入口 | 行情上方提供锚点入口 |
| 页面样式 | 较紧凑的顶部、柔和的提示条、统一卡片与表单、数字对齐，沿用旧版绿涨红跌并保留正负号 |

日涨跌基于 `quote.previous_close`，不能从图表首个样本推算。`quote.local_price` 与 `quote.local_currency` 缺失时，本币报价显示“—”。执行价格仍由后端确定；前端仅提示交易时段和报价时效。演示目录仍为明确标注的测试数据。

## 后续补齐

本轮新增多周期图表/K 线、外部搜索与申请、排行榜、追加保证金与爆仓价、管理页面、打赏明细、奖励明细和红包参数。目录已解除 200 个标的截断；列表缩略历史限制为 16 点，详情单独请求图表。分类、搜索、排序和页码使用浏览器会话存储恢复。

列表仍采用“选标的 → 联动下单”的操作方式，未恢复每行独立的买卖按钮；图表使用 SVG，未移植旧图表库的拖动缩放工具。数据源轮询与图表币种说明见 [剩余迁移记录](migration-completion.md)。

实际截图位于 `docs/screenshots`，包含股市桌面/手机、排行榜、管理页、赛事和帖子打赏汇总。
