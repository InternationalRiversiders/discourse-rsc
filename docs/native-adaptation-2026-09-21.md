# RSC 原生适配与旧版差异修补（2026-09-21）

> 后续补全、完整数据演练及最新验收见 [迁移补全记录](completion-2026-09-21.md)。本文中的较早待办与测试计数保留作历史记录。
范围：RiversideCoin 和 rsc_reward_to_post，排除棋牌游戏。本轮更新已有原生试用插件，并部署到两个独立私有测试库；没有安装到生产、没有切换旧 RSC、没有修改线上资金。

## 原生集成的选择

钱包、打赏、红包、交易和预测使用论坛会话、CSRF 和插件自己的 Rails 接口。帖子不再通过 `/app-rsc-api/auth/session-exchange` 换取 JWT，也不请求旧 Express 服务。浏览器仍需调用同源接口，但无需维护一个额外的公开 RSC 登录/账务后端；将来的 App 是否需要专用接口，留待实际调用清单核对。

只读检查了生产已启用的 62 个插件及主题源码。确认的 RSC 专用集成是附在 Horizon 上的主题组件「RSC 打赏」（theme 39）；未发现其他已安装插件直接实现旧 `/app-rsc-api` 调用。其他主题的文本匹配包含误匹配，不能据此声称它们实现了 RSC 功能。

- 原生帖子按钮打开 Discourse 弹窗，显示接收人和可用余额，提交支持幂等重试。
- 同一话题的可见帖子合并请求打赏汇总，最多 100 个帖子一批；保留旧打赏、用户卡、时间和长列表滚动，隐藏帖和无权限话题不泄露汇总。
- 本机旧主题源码增加原生插件启用时退出的条件，生产主题尚未修改。切换时应停用 theme 39，或发布并核对这条兼容条件。未更新的旧主题不能直接视为兼容。
- 通知事件与交易在同一数据库事务内保存，提交成功后排队投递；分钟任务负责失败重试，通知与已投递标记原子提交以防重复。
- 转账、打赏、红包领取/退款、奖励、委托成交/退款、平仓、止盈止损、爆仓、预测结算使用论坛通知。金额展示截断、保留原始精度；转账和领取通知标明对方。
- 红包通知跳到 token 页面，订单通知选中标的并显示指定本人订单，预测通知能打开旧已结算比赛，钱包通知打开指定本人流水；离开页面时清除临时定位参数。
- 使用与另外五个原生功能相同的 `river_app` 通知字段，避免多个 custom 通知 renderer 的注册顺序冲突。帖子通知仍使用原生话题/楼层链接。

## 验证与数据保护

- PostgreSQL 账务测试：17 项 / 70 断言，覆盖金额精度、并发、幂等、原子性和不可修改历史。
- Discourse 集成覆盖旧测试及新增规则、匿名汇总权限、流水分页/归属、旧待结算比赛、申请和未来豁免、初始保护条件、通知幂等。62 项 / 361 断言通过；连同底层账务合计 79 项 / 431 断言。
- `node test/estimate-test.mjs` 验证最小金额精度、预测返还和三种成交模式的可负担数量边界；`node test/format_test.mjs` 的 12 项展示检查、4 项 Python 只读导出测试通过。
- 浏览器使用真实论坛登录、CSRF 和实际接口，完成转账、红包、委托、追加保证金、预测、打赏、排行榜、管理员操作、通知定位、手机列表返回，无页面 JS 运行时错误。与增加兼容条件的旧主题同时加载时，只有原生按钮且没有旧 RSC API 请求。
- 私有部署先备份两个数据库，再迁移字段和补元数据。真实快照 4,341 个账户、4,384 条分录、44 个期初日志、232 个持仓、4,608 个订单、3,511 条预测、52 个红包、488 条领取、621,691 行原始归档的资产/账务摘要均一致。补元数据没有记账、没有重放通知。快照保持只读，实时来源和通知关闭。
- 私有浏览器核对了钱包、股市、预测、排行榜的深浅色及 390/1440 宽度，另外五个应用页面可同时打开；真实只读站有 1,638 个启用标的，后台可分页检索完整 2,508 个标的，写请求返回 503，4 个待收录申请标的可见。
- 原生按钮的有效范围、旧接口权限、默认关闭及只读设置均保留。没有公开真实数据或凭据，没有向 Git 远端推送。

## 仍不能据此直接接管生产

1. 行情和赛事的长期实际来源验收：当前私有容器没有外部网络，只刷新演示报价。REST 调度的真实配额、持仓覆盖、延迟、进程重启和 Sidekiq 持续运行仍需验证，不能用合成行情通过代替。当前对任何非虚拟币延迟报价采用确认模式，比旧仅对 Yahoo 延迟源的规则更保守；付费实时源配置需核对。
2. 收益率更正：后续已核对运行中旧服务，当前收益率并不使用遗留 TWR 引擎。原生报表沿用总盈亏 / 还原本金口径，历史观测节点保留；不再将另建连续 TWR 列为当前功能迁移阻塞项。
3. 最终资产归属和冻结切换：一个缺失论坛身份的钱包尚有 1 RSC，必须明确承接方式；随后停写旧系统、获取最新快照并全量对账。当前真实预览是旧快照及可映射账号子集。
4. 生产组合与入口：私有站加载这六个自研插件，不等于生产 62 个插件和 Horizon 全部组件的组合验收；正式停用旧打赏组件、旧红包/旧域名跳转和 App 实际调用核对尚未执行。旧生产服务及接口继续运行。
