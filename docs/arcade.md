# 街机区

`/rsc/games` 分为街机区和博弈区，记住上次栏目；资金流水深链仍进入博弈区记录。七款街机游戏免费参与，服务端复核操作记录计算成绩。

当前完整规则与存档说明见 [Flutter 复用与赛季](arcade-flutter.md)，App 接入见 [WebView 协议 v1](arcade-embed.md)。不要再根据初版有限时长、逐步联网的旧说明实现客户端。

- 当前规则版本 2：取消倒计时、步数及投放次数上限；自然失败结束。打砖块可连续过关，多款游戏渐进提速。
- 前后端共享规则引擎。实时游戏按批同步，2048 使用有限随机预取和操作批次；不公开完整种子，不接受客户端自报分数。允许程序策略。
- 游戏有效操作刷新 30 天存档期限；每 64 批折叠到服务端权威检查点和摘要，不无限保留完整逐帧输入。
- 总排行永久，每人每游戏最高分；当期轮替游戏另有赛季榜。管理员同样参与排名与奖励。停用/封禁用户和冻结钱包仍受正常资格检查。
- 默认按周轮替，也可配置按天；后台奖励开关与每期快照决定是否发奖，不硬编码“永远关闭”。当前预算前五名 100/60/40/25/15 RSC，并列共享所占名次奖金。
- 当前赛季直接使用新版规则，历史测试成绩保留。赛季截止计入此前已验证的检查点；跨期继续的旧局不计入新赛季。
- 论坛与 App 嵌入页面共用完整 UI、键位和触控；SDK 不等于完整页面，App 优先使用正式嵌入入口。

发布前验证后端规则与回放、前端真实操作、资源指纹及 WebView 协议。前端完整编译后，按工作区 AGENTS.md 的 A/B 容器切换流程上线；数据库兼容与回滚按实际变更检查。
