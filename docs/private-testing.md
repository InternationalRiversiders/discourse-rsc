## 连接

在自己的电脑运行，SSH 地址使用平时登录这台服务器的地址：

```sh
ssh -N -L 13000:127.0.0.1:13000 -L 13001:127.0.0.1:13001 用户名@服务器IP
```

保持终端连接，然后访问：

| 地址 | 数据及用途 | 账号 |
| --- | --- | --- |
| http://127.0.0.1:13000/rsc/market | 真实旧库快照，只读；查行情列表、历史 K 线、排名、交易档案及活动记录 | `rsc_preview_admin` |
| http://localhost:13001/rsc | 演示资产，可操作；测试交易、转账、红包、预测、打赏和通知 | `rsc_alice` |
| http://localhost:13001/rsc/admin | 演示站后台 | `rsc_admin` |

密码保存在服务器上的私有文件中，权限为 0600，不在 Git 或文档内：

```sh
cat /opt/rsc-private-preview/snapshot-login.json
cat /opt/rsc-private-preview/demo-login.json
```

第二个文件的顶层是普通测试账号，`admin` 字段是演示管理员。可以向演示账号 `rsc_bob` 转账。真实预览用 `127.0.0.1`，演示站用 `localhost`，避免两个数据库的登录 cookie 相互覆盖。

真实快照时间为北京时间 2026-09-21 03:43，之后旧系统的操作不在此快照中。真实论坛密码、邮箱和会话没有复制；导入身份仅供展示。真实预览的管理员新建于隔离数据库，可以通过 Discourse 后台在该测试站查看用户。

所有历史报价都明确标为快照，可用于标明依据的报表估值，不能用于成交或自动爆仓。网络隔离意味着本测试入口不获取外部实时行情。演示站仅刷新 `demo` 标记的合成价格。两个测试数据库分别使用 Redis DB 2 / 0，不运行生产 Sidekiq。

## 运维

私有代理仅监听 `127.0.0.1:13000` 和 `127.0.0.1:13001`。容器继续为 `--network none`，代理通过受限的固定目标网络命名空间转发；没有公开端口或生产 Nginx 改动。

```sh
sudo systemctl status rsc-private-snapshot rsc-private-demo rsc-private-demo-tick rsc-private-proxy
```

四个独立服务已设置开机启动。容器的 PostgreSQL 位于它自身的 `/tmp/rsc-pg`，不是生产目录。删除该容器会删除其可写层；移除前先保存备份。原始可恢复快照仍在 `/opt/riverside-backup/rsc-native-rehearsal-20260920T194336Z`，新测试库备份保存在 `/opt/rsc-private-preview`。

停止这些测试入口：

```sh
sudo systemctl stop rsc-private-proxy rsc-private-demo-tick rsc-private-demo rsc-private-snapshot
```

测试登录资料仅适用于这两个私有站，不能用于正式论坛。
