# 原生页面与运行方式

钱包、红包、股市、赛事预测、排行榜和管理页均运行在 Discourse 内；后端为插件 Rails Engine，前端为原生 Ember/GJS 页面。没有嵌入旧 Next.js 页面，也不调用旧 Express 服务。详细功能和边界见 [迁移记录](migration-completion.md)。

## 插件如何工作

- `plugin.rb` 注册站点设置、样式、序列化字段、控制器和后台任务。
- `db/migrate` 创建插件自己的 PostgreSQL 表，数据库约束保护会计分录和历史。
- `/rsc` 及子路由共享论坛登录态、CSRF、用户组权限和主题；前端路由采用当前目录结构，页脚使用原生生命周期 helper。
- 钱包转账、下单、预测和红包通过同库事务执行；资金预留使用托管账户，重试使用幂等编号。
- Discourse/Sidekiq 负责行情、赛事、交易检查、红包到期、奖励和通知。
- 帖子打赏使用原生帖子菜单和弹窗；通知直接进入头像菜单，能跳到帖子、钱包、股市或赛事。

## 用户入口

| 路径 | 内容 |
| --- | --- |
| `/rsc` | 钱包、转账、今日奖励、发红包、流水和迁移前历史 |
| `/rsc/market` | 行情列表、分类搜索、图表、交易、持仓及委托 |
| `/rsc/sports` | 多联赛筛选、赔率、预测和结算记录 |
| `/rsc/packets/:token` | 红包分享、领取、收回和领取明细 |
| `/rsc/leaderboard` | 资产、盈亏、收益率和成交次数排名 |
| `/rsc/admin` | 钱包、资产、标的、奖励、赛果及审计管理 |

普通用户仅能操作自己的资金和订单，管理员接口独立校验权限。客户端不能指定发送人、成交价格或预测派奖金额。

## 当前运行边界

插件默认关闭。本机代码已在同版本的独立 Discourse 容器验收；尚未发布远端，也未加入生产论坛。首次应在测试站加载插件并执行迁移，再启用 `rsc_enabled`、`rsc_native_trial_enabled`，配置允许用户组和管理组。

行情、赛事、高风险交易和每日奖励各有独立开关。高风险模式除后台开关外还要求下单用户勾选。真实数据源适配与演示数据脚本分开；测试用 `demo_tick.rb` 不属于生产任务。

每日奖励直接读取论坛帖子和访问记录。正式切换前应停用旧 RiversideCoin 奖励任务，并导入已发放记录避免重复。`rsc_reward_to_post` 是打赏主题组件，切换时停用该主题组件以免出现两个打赏入口。

安装代码与迁移真实资产是两件事。正式切换必须先验证全量导入报告、供应商时效和定时任务；导入及对账步骤见 [迁移记录](migration-completion.md)。本次没有执行生产切换。

默认 `rsc_read_only=true`：即使打开 `rsc_enabled` 与 `rsc_native_trial_enabled`，仍只读。仅在隔离的合成数据测试库中设为 false 来测试资金操作；真实快照预览保持 true。已配置的两个私有入口见 [连接说明](private-testing.md)。
