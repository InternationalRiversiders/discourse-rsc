# RS Coin 页面宽度与下单面板

2026-09-23 调整：取消论坛外框的宽度覆盖，侧栏和外框完全沿用主题布局；仅在 RSC 内容区内限宽居中，市场内容上限 1440px，钱包 1240px，排行榜 1280px；桌面额外保留两侧各 12–24px 的内容区内留白，手机沿用原边距。排行榜默认展示排名、用户、总资产、总盈亏、收益率和成交次数；选择持仓权益、已实现盈亏或浮动盈亏排序时，临时显示对应指标列。展开交易档案时列跨度同步变化。

历史方案（外框覆盖现已移除）2026-09-22：RS Coin 使用侧栏以外的可用空间，外层最大宽度 1920px。针对 Horizon 对主内容设置的 1000px 上限，覆盖仅作用于 `.rsc-app`；离开 RS Coin 后，论坛页面仍使用主题布局。

股市不再自动选中第一个品种。未选中时持仓和市场列表占满工作区，走势图及下单面板不挂载。点击品种或持仓名称只显示行情；点击做多/做空或「交易此品种」才展开下单。「收起下单」保留当前输入，「返回市场」关闭整个详情区。通知中的品种直达链接仍能打开行情；无效品种编号不会默认落到其他品种。关闭详情会销毁走势图轮询，现有市场全局刷新频率不变。
